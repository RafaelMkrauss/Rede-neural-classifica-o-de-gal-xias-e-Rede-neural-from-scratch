# Rede-neural-classifica-o-de-gal-xias-e-Rede-neural-from-scratch
Dois modelos de redes neurais aplicados por fins diversos, o primeiro é desenvolvido usando o pytorch e preve classes entre galáxias, estrelas e quasares e mostram testes encima da rede neural e seus parâmetros.
